# 출하 검수 체크리스트 (자동 생성)

### 01 하부 트레이와 고무발
- [ ] 트레이 크랙·버(burr) 없음
- [ ] 고무발 4개 수평 확인

### 02 강판 섀시와 스탠드오프
- [ ] 섀시–트레이 간 유격 없음
- [ ] 스탠드오프 6개 높이 균일

### 03 PX-80 메인보드 고정
- [ ] 기판 휨 없음
- [ ] 접지 나사(★표시) 톱니와셔 체결

### 04 IC 실장: CPU · EEPROM · SRAM · Pico · XTAL
- [ ] 모든 IC 노치 방향 일치
- [ ] 휜 핀 없음 (루페 확인)

### 05 전원부: 트랜스 · 방열판 · C1
- [ ] 레귤레이터 탭–방열판 절연 ≥ 10 MΩ
- [ ] C1 극성 확인
- [ ] AC 1차측 수축 튜브 처리

### 06 USB 저장장치 베이 (CH376S)
- [ ] USB 메모리 삽입 걸림 없음
- [ ] 접근 LED 창 정렬

### 07 배선 하네스: 리본 · 전원 · 스피커
- [ ] 커넥터 역삽 없음
- [ ] 배선이 상판 리브와 간섭 없음

### 08 상판과 전면 다이얼
- [ ] 상판–트레이 단차 ≤ 0.3 mm
- [ ] 다이얼 회전 걸림 없음

### 09 틸트·스위블 스탠드
- [ ] 스위블 ±90° 부드러움
- [ ] 틸트 −5° ~ +12° 유지력

### 10 슬림 베젤과 전면 유리
- [ ] 베젤–유리 간격 균일
- [ ] 노브 축 정렬

### 11 19" 16:10 CRT 튜브 삽입
- [ ] 튜브 전면–베젤 밀착
- [ ] 아쿠아닥 접지 스프링 접촉

### 12 편향 요크와 넥 보드
- [ ] 요크 회전 고정
- [ ] 넥 소켓 완전 삽입

### 13 플라이백과 디가우싱 코일
- [ ] 애노드 캡 밀착
- [ ] 고압선–섀시 거리 ≥ 20 mm

### 14 슬림 후면 셸
- [ ] 셸 통풍구 막힘 없음
- [ ] 라벨(정격) 부착

### 15 키보드 케이스와 매트릭스 PCB
- [ ] 다이오드 방향 49/49
- [ ] DIN 케이블 스트레인 릴리프 체결

### 16 키캡 장착
- [ ] 키캡 높이 단차 없음
- [ ] 스페이스바 양끝 고르게 눌림

### 17 마우스 볼과 초퍼 엔코더
- [ ] X/Y 휠 걸림 없이 회전
- [ ] 볼 케이지 먼지 제거

### 18 마우스 상부 셸
- [ ] 좌·우 버튼 클릭감 동일

### 19 케이블 연결: 키보드 · 마우스 · 비디오
- [ ] 커넥터 완전 삽입
- [ ] 케이블 꺾임 반경 ≥ 30 mm

### 20 전원 투입과 POST 검수
- [ ] POST 전 항목 OK
- [ ] +5V 4.90–5.10 V
- [ ] H-SYNC 15.734 kHz 고정
- [ ] 키 49개 입력 확인
