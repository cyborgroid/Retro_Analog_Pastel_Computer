# Assembly 환경

20단계 조립 과정을 3D로 재생합니다. 구현은 `src/js/assembly/assembly.js`, 단계 데이터는 `src/js/data/assembly.js`에 있습니다.

## 동작

- 각 3D 부품은 `model.js`에서 자신의 조립 단계와 날아오는 방향(`from`)을 등록합니다. 타임라인이 진행되면 단계별로 부품이 나타나 제자리에 끼워집니다(ease-out).
- 단계를 바꾸면 카메라가 그 단계에 맞는 시점으로 이동합니다.
- **재생**은 단계를 자동으로 넘깁니다(속도 0.5× – 4×). 슬라이더로 타임라인을 직접 움직일 수도 있습니다.
- 조립 중에는 CRT가 꺼져 있습니다. 20단계(전원 투입)에 도달하면 전원이 들어오고 BIOS POST가 시작됩니다.
- 검수 체크박스는 브라우저에 저장되며(localStorage), 진행률 막대에 반영됩니다.

## 공정 요약

| 구간 | 단계 | 내용 |
|---|---|---|
| 본체 | 01–08 | 트레이 → 섀시 → 메인보드 → IC → 전원부 → FDD → 하네스 → 상판 |
| 모니터 | 09–14 | 스탠드 → 베젤 → 튜브 → 요크 → 플라이백 · 디가우스 → 후면 셸 |
| 키보드 | 15–16 | 케이스 · 매트릭스 PCB → 키캡 |
| 마우스 | 17–18 | 볼 · 엔코더 → 셸 |
| 마무리 | 19–20 | 케이블 → 전원 투입 · POST 검수 |

총 예상 시간은 109분입니다. 단계별 세부 내용은 [steps.md](steps.md), 나사와 토크는 [fasteners.csv](fasteners.csv), 출하 검수는 [qc-checklist.md](qc-checklist.md)를 보세요(세 파일 모두 자동 생성).

## 안전

- 11–13단계(CRT 튜브, 요크, 플라이백)는 고압 부품입니다. 방전 프로브로 애노드를 방전한 뒤 작업하고, 튜브는 반드시 2인이 다룹니다.
- 3–4단계에서는 정전기 손목띠를 섀시 접지 러그에 연결합니다.
