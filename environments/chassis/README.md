# Chassis 환경

외형, 재질, 색, 치수를 3D로 검토합니다. 구현은 `src/js/chassis/`(geometry · model · viewer · cad · chassis)에 있습니다.

## CAD v3 (Rust) 와 웹 v2

3D 뷰는 기본으로 **실제 제작판** 모델을 표시합니다. `cad/spec.json`에서 Rust가 만든 형상(`cad/out/build/web/pastella84.glb`)으로, 19" LCD 패널과 3D 출력 하우징으로 지금 만들 수 있는 구성이고 STEP · URDF · USDA와 같은 형상입니다. **컨셉 (CRT)**를 고르면 워크벤치가 시뮬레이션하는 CRT 설계(`cad/out/web/pastella84.glb`)를 봅니다. 이 두 모드에서는 BOM의 치수와 질량도 Rust 빌드 값(`src/js/data/cad.js`)을 쓰고, 출력 계획 · BOM · DXF를 바로 받을 수 있습니다. 자세한 내용은 [cad/README.md](../../cad/README.md)를 보세요.

"웹 v2"를 고르면 three.js로 직접 그린 이전 모델로 돌아갑니다. 분해도와 파라메트릭 모니터는 웹 v2에만 적용되며, Assembly 탭의 조립 애니메이션도 웹 v2 모델을 씁니다. 실물 참고 사진의 출처는 [references.md](references.md)에 있습니다.

## 기능

- **파라메트릭 와이드 모니터**: 화면 크기 14–22", 비율 4:3 · 16:10 · 16:9, 베젤 6–40 mm를 조정할 수 있습니다. 바꾸면 3D 모델, CRT 화면 캔버스 비율, BOM이 함께 다시 만들어집니다. 기본값은 **19" 16:10, 베젤 12 mm**입니다. 자세한 내용은 [monitor-wide.md](monitor-wide.md)를 보세요.
- **분해도**: 본체 상판, 모니터 전체와 후면 셸, 키캡, 마우스 셸이 분리됩니다.
- **단면 보기**: X축 클리핑 평면으로 내부를 자릅니다.
- **표면 마감**: 유광(0.15)부터 무광(0.85)까지 거칠기를 바꿉니다.
- **야간 조명**: 실내 조명을 낮추고 CRT 화면의 빛이 주변을 비춥니다.
- **컬러웨이**: 5종 프리셋과 부품별 7가지 색 역할. 정의는 [colorways.json](colorways.json)에 있습니다.
- **부품 선택**: 3D에서 클릭하면 사양이 표시됩니다. 설명 데이터는 [parts.json](parts.json)에 있습니다.

## 치수

외형 치수와 질량은 [dimensions.csv](dimensions.csv)를 보세요. CAD v3 빌드가 생성하는 값입니다(W × H × D, 질량은 B-rep 부피 × 밀도, 주요 부품은 지정 질량).

## 좌표계

- 1 단위 = 100 mm, Y가 위쪽, +Z가 사용자 쪽입니다.
- 본체 중심 (0, 0, −0.7), 상판 윗면 y = 1.13
- 모니터 그룹 원점 (0, 1.13, −0.85), 스탠드 높이 30 mm
- 키보드 (0, 0, 2.25), 6° 경사 / 마우스 (3.35, 0, 2.35)
