# 부품 조달 원칙: 실재하고 구하기 쉬운 재료

모든 회로는 지금 실제로 살 수 있는 부품 번호로 그렸습니다. 전체 목록은 [bom-sourcing.csv](bom-sourcing.csv)(자동 생성)에 있고, Circuit 탭 아래 "부품 조달" 표에서도 볼 수 있습니다.

## 단종 부품 → 생산 중인 부품

| 원래 설계 (1984 감성) | 바꾼 부품 | 이유 |
|---|---|---|
| 4164 DRAM × 8 | AS6C62256 SRAM × 2 | DRAM은 단종이고 리프레시 회로가 필요합니다. SRAM은 생산 중이고 회로가 단순합니다. |
| 마스크 ROM | AT28C256 EEPROM | 범용 프로그래머로 다시 쓸 수 있습니다. |
| TMS9918A VDP | Raspberry Pi Pico (RP2040) + 74LVC245 | TMS9918A는 중고만 있습니다. Pico의 PIO로 NTSC 컴포지트를 만듭니다. |
| AY-3-8910 PSG | Raspberry Pi Pico PWM + RC 필터 + LM386 | 원본은 단종이고, Pico로 3채널과 노이즈를 에뮬레이션합니다. |
| WD1772 FDC + 3.5" FDD | CH376S USB/SD 모듈 + Gotek 형태 베이 패널 | FDC와 FDD 모두 단종·중고입니다. 3D 외형은 그대로 두고 슬롯에 USB 포트를 둡니다. |
| 8255 PIO | 74HC138 + 74HC541 + ATmega328P | 흔하고 싼 부품입니다. 마우스 직교 디코딩은 ATmega가 맡습니다. |
| 리프 스프링 스위치 | Gateron / Cherry MX 호환 스위치 | 쉽게 구할 수 있습니다. |

## 그대로 둔 것과 그 이유

- **Z80 (Z84C0010PEG)**: Zilog가 2024년 단종을 발표했지만 재고와 호환품이 많고, RC2014 같은 레트로 키트 생태계가 큽니다. 꼭 생산 중인 CPU를 원하면 W65C02S를 쓸 수 있지만, 버스 타이밍(로직 분석기 화면)이 달라집니다.
- **CRT**: 신품 CRT는 생산되지 않습니다. Chassis는 CRT 외형을 유지하되, 실제 제작은 19" 16:10 LCD + 컴포지트 입력 보드를 레트로 셸에 넣는 방식을 권장합니다. Circuit 탭의 수평 편향 회로는 중고 CRT를 쓸 때의 참고 회로입니다(2SC5144, 플라이백은 수리 부품으로 유통).

## 양자 부품의 현실

| 부품 | 현실 | 쉬운 대안 |
|---|---|---|
| 트랜스몬 칩 | 나노팹 공정이 필요한 연구소급 | 클라우드 QPU (IBM Quantum Open Plan) |
| 희석 냉동기 | 연구소급 고가 장비 | 클라우드 · 상온 NMR 교육용 기기 (SpinQ Gemini Mini) |
| AWG · LO · IQ · ADC | 상용 계측기는 고가 | QICK + RFSoC 4x2 보드 |
| HEMT · TWPA | 연구소급 | 클라우드 사용 시 불필요 |
| Q-Bus 브리지 | — | Raspberry Pi Pico W (생산 중, 쉬움) |
| 원리 실습 | — | 레이저 + 편광판 + 파장판 (1큐비트 회전의 고전 광학 아날로그) |

즉 본체는 전부 쉽게 구할 수 있는 부품으로 만들 수 있습니다. 양자 계산은 Pico W 브리지 → PC → 클라우드 QPU 경로가 현실적인 방법입니다.
