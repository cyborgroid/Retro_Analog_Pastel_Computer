# 트랜스몬 큐비트 · 제어 · 냉각 · 판독

구현: `src/js/circuit/qubit.js`, `qcontrol.js`, `cryo.js`, `readout.js`. 물리 모델: `src/js/quantum/hardware.js`.

## 1. 트랜스몬 (Q0)

조지프슨 접합 2개로 만든 SQUID가 비선형 인덕터 역할을 하고, 션트 커패시터 CΣ와 함께 비조화 진동자(인공 원자)를 이룹니다.

```
H = 4·EC·(n − ng)² − EJ(Φ)·cos φ
EJ(Φ) = EJmax · |cos(π Φ/Φ0)|          (대칭 SQUID)
f01 ≈ √(8·EJ·EC) − EC
α ≈ −EC                                 (비조화성: f12 = f01 + α)
```

| 기본값 | 값 |
|---|---|
| EJmax | 14.0 GHz |
| EC | 260 MHz |
| f01 (Φ = 0, 스윗 스폿) | 5.136 GHz |
| EJ/EC | 54 (전하 잡음에 둔감하려면 ≥ 20) |
| 판독 공진기 fr | 7.05 GHz, κ = 1 MHz, g = 100 MHz |
| 분산 이동 χ | ≈ 0.63 MHz (2χ = 1.25 MHz) |

스윗 스폿(Φ = 0)에서는 df/dΦ = 0이라 플럭스 잡음에 1차로 둔감합니다. 벗어나면 Tφ = 120 µs / (1 + 40|sin πΦ|)로 줄어듭니다.

**보정**: "자동 보정"은 실제 실험의 두 단계를 흉내 냅니다. 분광으로 구동 주파수 fd를 f01에 맞추고, 라비 실험으로 π 펄스 진폭을 맞춥니다. 보정 뒤에 플럭스나 EJ/EC를 바꾸면 이조 Δ = f01 − fd가 생기고, 블록 작곡기 결과가 나빠집니다.

## 2. 마이크로파 제어 체인

- AWG(2 GS/s, 16 bit)가 IF 50 MHz의 40 ns 가우시안 펄스를 I/Q로 냅니다. DRAG를 켜면 Q에 미분 성분을 더해 |2⟩ 누설을 줄입니다.
- IQ 믹서가 LO 4.95 GHz와 곱해 5.00 GHz로 올립니다. 그다음 BPF와 DC 블록을 거쳐 냉동기로 내려갑니다.
- 감쇠: 4 K −20 dB, Still −10 dB, MXC −20 dB (합계 −50 dB). 상온 열잡음 광자를 줄입니다.
- 플럭스선: AWG Z + DC 바이어스 → 바이어스-T → Eccosorb 필터 → MXC LPF.

라비 모델(진폭 k, 정규화 이조 δ = Δ / 12.5 MHz):

```
P(|1⟩) = k² / (k² + δ²) · sin²(π/2 · √(k² + δ²))
```

## 3. 희석 냉동기

| 단 | 기저 온도 | 역할 |
|---|---|---|
| 50 K | 45 K | 펄스 튜브 1단, 복사 차폐 |
| 4 K | 3.2 K | 펄스 튜브 2단, HEMT |
| Still | 0.9 K | ³He 증류 |
| CP | 100 mK | 감쇠기 열 고정 |
| MXC | 10 mK | 혼합실, QPU · TWPA |

- 열적 들뜸: p = 1 / (1 + exp(h·f01 / kT)). 10 mK에서는 사실상 0이고, 100 mK에서는 약 8 %입니다.
- 준입자: T1 = T1₀ / (1 + 4×10⁶ · e^(−2.1 K / T)). 150 mK 근처부터 급격히 무너집니다.
- 벤치에서는 실제 약 2일 걸리는 냉각을 40초, 워밍업을 25초로 가속합니다.

## 4. 분산 판독

- 큐비트가 \|0⟩이면 공진기가 fr − χ, \|1⟩이면 fr + χ에 있습니다. 두 주파수의 가운데로 톤을 보내 위상을 읽습니다.
- 광자 수 n = 10^((P + 130) / 10). 임계 광자 수 n_crit = (Δ / 2g)² ≈ 91을 넘으면 측정 유도 전이가 생깁니다.
- SNR = 3 · √(n · τ) · G. G는 TWPA가 켜지면 1, 꺼지면 0.3, HEMT가 고장 나면 × 0.05입니다.
- 판정 오류 = ½·erfc(SNR / 2√2) + τ / (2·T1) + 측정 유도 전이 항.

| 판독 전력 · 적분 · TWPA | SNR | 오류 |
|---|---|---|
| −125 dBm · 1 µs · 켜짐 | 5.3 | ≈ 0.9 % |
| −125 dBm · 1 µs · 꺼짐 | 1.6 | ≈ 21 % |
| −110 dBm · 1 µs · 켜짐 | 30 | ≈ 3.4 % (n = 100 > n_crit) |
| −100 dBm · 1 µs · 켜짐 | 95 | ≈ 31 % (측정 유도 전이) |

## 오류율 요약 (기본값)

- 1Q 게이트(40 ns): p1 = (tg / 3)(1/T1 + 1/T2) + 누설 ≈ 7×10⁻⁴
- 2Q CZ(200 ns): p2 ≈ 0.012
- 판독: ≈ 0.9 %
