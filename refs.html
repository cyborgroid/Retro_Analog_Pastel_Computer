레퍼런스 이미지 수집 브라우저 → 로컬 서버

원하는 이미지 검색 결과 페이지를 브라우저에서 직접 연 뒤, 아래 스크립트를 그 페이지의 개발자 도구 콘솔에 붙여 넣으세요. 페이지가 이미 불러온 이미지 목록만 읽고(스크롤로 더 불러옴) 이 서버로 보냅니다. 검색어 하나는 보통 수백 장에서 끝나므로, 많이 모으려면 관련 검색어로 여러 번 실행하세요. 중복은 자동으로 합쳐집니다.

  1. 검색 결과 페이지를 엽니다 (예: Google 이미지 탭).
  2. 수집 스크립트 복사를 누르고, 그 페이지에서 F12 → Console에 붙여 넣고 Enter.
  3. 오른쪽 아래 배지에 개수가 오르다 멈추면 자동 전송됩니다. 전송이 막히면 JSON 파일이 저장되니 아래 칸에 끌어다 놓으세요.
  4. 다운로드 · 분석 시작을 누르면 원본 사이트에서 받아 중복 제거 · 색 분석 · 비교표를 만듭니다.
